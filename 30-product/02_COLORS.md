# COLORS

Version 1.0

---

# Philosophy

Color is not decoration.

Color communicates information.

The CAS interface relies primarily on typography, spacing and hierarchy.

Color exists only to reinforce meaning.

Dark neutral tones create focus.

Accent colors guide attention.

No color should exist without purpose.

---

# Core Identity

The visual identity of CAS is inspired by:

• Combat sports gyms

• Professional training facilities

• Scientific laboratories

• Precision equipment

• Industrial materials

The dominant impression should be:

Calm.

Technical.

Robust.

Timeless.

# Graph Colors

Graphs communicate performance,

not decoration.

Recommended order:

Performance Orange

Recovery Green

Light Gray

Steel Gray

Critical Red (only when necessary)

Never use rainbow palettes.

Never use more than five colors in one graph.

# Color Usage Rules

Dark backgrounds dominate.

Accent colors remain rare.

White space is preferred over colored surfaces.

Never create screens dominated by orange.

Never use gradients.

Never use neon colors.

Never use glowing effects.

Never use decorative shadows.

---

# Accessibility

Minimum contrast should satisfy WCAG AA.

Important information must never rely exclusively on color.

Icons.

Typography.

Spacing.

Labels.

must always reinforce meaning.

---

# Final Principle

When color disappears,

the interface should still remain understandable.

If removing color breaks usability,

the design depends too much on color.
