# TYPOGRAPHY

Version 1.0

---

# Philosophy

Typography is the primary communication tool of CAS.

Hierarchy should come from typography before color.

The interface should remain perfectly understandable even in grayscale.

Typography communicates structure.

Not emotion.

Every text element should answer one question:

Does it help the athlete make a better decision?

If not,

remove it.

---

# Design Principles

Typography must feel:

Calm.

Professional.

Technical.

Timeless.

Readable under fatigue.

Readable in bright sunlight.

Readable in a dark gym.

Readable at arm's length.

The athlete should never need to zoom or concentrate to read information.

# Numerical Values

Numbers are among the most important information inside CAS.

Loads.

Repetitions.

Rest timers.

Heart rate.

Velocity.

Performance metrics.

Numbers should always appear visually stronger than surrounding text.

Large.

Clear.

Easy to compare.

---

# Text Hierarchy

The athlete should instantly distinguish:

Primary information

↓

Current exercise

↓

Performance metrics

↓

Instructions

↓

Supporting information

↓

Metadata

The hierarchy should never require conscious effort.

---

# Line Length

Keep text short.

Prefer one sentence.

Avoid long paragraphs.

Training environments demand rapid reading.

---

# Alignment

Text is left aligned.

Numbers may be right aligned inside tables.

Never justify paragraphs.

Center alignment should remain exceptional.

---

# Capitalization

Use Sentence case.

Correct

Today's session

Recovery score

Exercise history

Incorrect

TODAY'S SESSION

Recovery Score

Today's Session

Avoid unnecessary capital letters.

---

# Emphasis

Never rely on color alone.

Use hierarchy instead.

Weight.

Spacing.

Size.

Position.

Bold should remain exceptional.

If everything is bold,

nothing is important.

---

# Buttons

Button labels should remain short.

Examples

Start session

Continue

Finish workout

Save

Cancel

Avoid long labels.

---

# Timers

Timers should be among the largest typography elements.

The athlete must read them instantly from several meters away.

# Accessibility

Minimum body size

16 pt

Touch interfaces require comfortable reading.

High contrast is mandatory.

Typography must remain readable under:

Sweat.

Stress.

Fatigue.

Movement.

Bright sunlight.

Dark gyms.

---

# Final Principle

If the athlete notices the typography,

it is probably doing too much.

Good typography disappears.

Only understanding remains.
