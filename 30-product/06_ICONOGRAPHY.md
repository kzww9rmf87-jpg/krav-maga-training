# ICONOGRAPHY

Version 1.0

---

# Philosophy

Icons exist to improve understanding.

Nothing more.

They are functional.

Never decorative.

Every icon should answer one question:

Would removing this icon reduce understanding?

If the answer is no,

remove it.

---

# Visual Identity

CAS icons should feel:

Professional.

Technical.

Minimal.

Timeless.

Quiet.

They should never compete with typography.

They should never become the focus of the interface.

---

# Style

Use outline icons.

Never filled icons as the default.

Avoid heavy visual weight.

Simple geometry.

Consistent proportions.

Clean lines.

Minimal detail.

---

# Icon Library

Preferred library

Lucide Icons

Reasons

• Open source

• Consistent

• Lightweight

• Modern

• Excellent React Native support

Alternative

SF Symbols

Used automatically on iOS whenever possible.

Never mix unrelated icon libraries.

---

# Stroke

Icons should use a consistent stroke width.

Never mix thin and thick icons.

The icon family should appear visually uniform throughout the application.

---

# Size Scale

Small

16 px

Supporting information.

---

Default

20 px

Lists.

Buttons.

Cards.

---

Medium

24 px

Navigation.

Section headers.

---

Large

32 px

Major status indicators.

Empty states.

Avoid icons larger than 32 px during normal navigation.

---

# Color

Icons inherit text color.

Primary actions

Performance Orange.

Secondary information

Secondary Text.

Disabled

Disabled Gray.

Errors

Critical Red.

Success

Recovery Green.

Icons should never introduce additional colors.

---

# Navigation Icons

Navigation icons should remain extremely simple.

No visual effects.

No shadows.

No gradients.

No filled backgrounds.

Selection is indicated through:

Color.

Weight.

Position.

Never animation.

---

# Exercise Icons

Exercise-related icons should represent actions.

Examples

Barbell

Running

Stretching

Timer

Heart Rate

Recovery

Avoid anatomical illustrations.

Avoid bodybuilding imagery.

Avoid aggressive symbols.

---

# Status Icons

Status should remain immediately understandable.

Success

Check

Recovery

Leaf

Fatigue

Battery

Moon

Recovery

Clock

Progress

Trending Up

Personal Best

Award

Warning

Triangle

Error

Circle Alert

The meaning should remain universal.

---

# Decorative Icons

Decorative icons are prohibited.

Every icon must communicate information.

If an icon does not improve understanding,

remove it.

---

# Empty States

Empty states may include one simple icon.

The icon should support the message.

Never dominate the screen.

---

# Animations

Icons remain static.

Animation is exceptional.

Allowed

Small rotation while loading.

Small appearance transition.

Subtle state change.

Not allowed

Bounce.

Spin loops.

Glow.

Pulse.

Elastic animations.

Attention-grabbing effects.

---

# Accessibility

Icons never replace text.

Important actions always include labels.

Icons should remain recognizable under poor lighting conditions.

Touch targets remain at least 44 × 44 px.

---

# Consistency

Identical actions always use identical icons.

Never change icons for stylistic variety.

Consistency builds recognition.

Recognition reduces cognitive load.

---

# Final Principle

The athlete should remember what the icon means.

Never what it looks like.

If an icon attracts attention,

it is probably doing too much.
