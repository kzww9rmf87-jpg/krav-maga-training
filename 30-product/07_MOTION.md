# MOTION

Version 1.0

---

# Philosophy

Motion exists to improve understanding.

Never entertainment.

Never decoration.

Never delight for its own sake.

Every animation should answer one question:

Does this help the athlete understand what just happened?

If not,

remove it.

---

# Design Principles

Motion should feel:

Natural.

Fast.

Calm.

Controlled.

Predictable.

The athlete should never wait for an animation.

The interface follows the athlete.

The athlete never follows the interface.

---

# Animation Hierarchy

Animations communicate:

State changes.

Progress.

Completion.

Focus.

Transitions.

Nothing else.

---

# Speed

Animations should remain short.

Micro interactions

100–150 ms

Standard transitions

200–250 ms

Large transitions

300 ms maximum

Nothing should ever feel slow.

---

# Screen Transitions

Screen changes should feel immediate.

Use subtle fade combined with slight movement.

Avoid dramatic transitions.

Avoid page flips.

Avoid zoom effects.

Avoid rotating elements.

The athlete should remain oriented.

---

# Cards

Cards may slightly elevate when pressed.

Movement should remain minimal.

The interaction should confirm touch,

not attract attention.

---

# Buttons

Buttons provide immediate feedback.

Allowed

Slight scale reduction while pressed.

Opacity adjustment.

Subtle color transition.

Not allowed

Bounce.

Elastic effects.

Glow.

Flash.

Explosion effects.

---

# Progress

Progress is animated.

Workout completion.

Rest timer.

Training block progression.

Recovery progression.

Progress should feel continuous.

Never abrupt.

---

# Timers

The timer is the visual rhythm of the workout.

Seconds should change smoothly.

No visual jump.

No distracting effects.

The athlete should perceive continuity.

---

# Rest Countdown

The final five seconds may receive additional emphasis.

Examples

Subtle vibration.

Slight typography emphasis.

Gentle color transition.

Never flashing.

Never blinking.

Never alarming.

---

# Loading

Loading reassures.

Never entertains.

Preferred

Skeleton loading.

Progress indicators.

Immediate feedback.

Avoid

Infinite spinners whenever progress can be estimated.

---

# Graphs

Graphs may animate once when appearing.

The animation helps explain the data.

Never replay animations repeatedly.

Graphs remain calm.

---

# Notifications

Notifications slide naturally.

Appear briefly.

Disappear automatically.

Never interrupt training unless necessary.

---

# Success Feedback

Workout completed.

Exercise saved.

Personal best recorded.

Feedback remains discreet.

Examples

Small checkmark.

Subtle fade.

Short haptic confirmation.

No celebration animations.

No confetti.

No fireworks.

---

# Error Feedback

Errors appear immediately.

Clear.

Calm.

Actionable.

Avoid shaking animations.

Avoid flashing red.

The interface should communicate confidence,

even when something fails.

---

# Empty States

Empty states may fade into view.

Nothing more.

The purpose is orientation.

Not decoration.

---

# Navigation

Navigation transitions should become invisible after repeated use.

The athlete should develop muscle memory.

Motion supports habit.

---

# Haptic Feedback

Haptics should reinforce important moments.

Recommended

Start workout.

Finish set.

Rest complete.

Workout complete.

Personal best.

Avoid haptics for ordinary navigation.

---

# Sound

CAS remains silent by default.

Audio exists only when explicitly enabled.

Examples

Voice guidance.

Rest countdown.

Workout completion.

Never use interface sounds for decorative purposes.

---

# Accessibility

Respect Reduced Motion settings.

When reduced motion is enabled:

Remove non-essential animations.

Maintain immediate feedback.

Never reduce usability.

Accessibility always overrides aesthetics.

---

# Consistency

Identical actions produce identical animations.

Consistency builds confidence.

Confidence reduces cognitive load.

---

# Final Principle

The athlete should notice progress.

Never animation.

If motion attracts attention,

it is probably doing too much.
