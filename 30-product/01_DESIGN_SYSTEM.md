# DESIGN SYSTEM

Version 1.0

---

# Purpose

The CAS Design System defines how the Combat Athlete System should look, feel and behave.

It is not a collection of visual components.

It is the visual expression of the CAS philosophy.

Every interface decision must reinforce the mission of CAS:

Helping combat athletes become more capable while reducing cognitive effort.

The interface exists to support training.

Never to become the center of attention.

---

# Design Philosophy

The application should communicate four emotions.

Calm.

Confidence.

Precision.

Strength.

Everything else is secondary.

The athlete should never feel overwhelmed.

Never feel judged.

Never feel distracted.

The interface should feel like professional equipment.

Reliable.

Robust.

Purposeful.

---

# Simplicity

Every screen should feel obvious.

Every action should feel natural.

Every interaction should disappear as quickly as possible.

Complexity belongs inside the engine.

Never inside the interface.

The athlete should think about the next repetition.

Not about the application.

---

# Visual Identity

CAS deliberately avoids the visual language of traditional fitness applications.

No flames.

No lightning bolts.

No exaggerated gradients.

No bodybuilding aesthetics.

No unnecessary visual effects.

The visual language is inspired by:

• professional training environments

• combat sports gyms

• scientific laboratories

• military equipment

The application should feel timeless.

Quiet.

Technical.

Professional.

The interface should feel closer to a precision instrument than to a social fitness app.

---

# Color Philosophy

Color communicates information.

Never emotion.

Never decoration.

The visual identity is built around dark neutral tones.

Graphite.

Steel.

Charcoal.

These colors communicate stability, focus and discipline.

Accent colors are used sparingly.

Primary Accent

Burnt Orange

Energy.

Action.

Performance.

Secondary Accent

Muted Green

Recovery.

Readiness.

Progress.

Neutral Colors

Graphite Black

Steel Gray

Light Gray

Off White

Warning

Amber

Danger

Deep Red

Only when required.

Large areas of saturated color should never dominate the interface.

Contrast should come from typography, spacing and hierarchy rather than color.

---

# Typography

Typography creates structure.

Not decoration.

Readable under fatigue.

Readable in bright sunlight.

Readable inside a dark gym.

Large titles.

Short sentences.

Minimal text.

Every piece of typography should improve understanding.

Never excitement.

---

# Icons

Icons communicate actions.

Nothing more.

Every icon must answer one question:

Does this improve understanding?

If the answer is no,

remove it.

Icons should feel technical.

Simple.

Consistent.

Minimal.

---

# Motion

Animation exists only to improve comprehension.

Transitions explain state changes.

Timers communicate rhythm.

Progress indicators communicate advancement.

Nothing should move without purpose.

Motion should feel:

Fast.

Smooth.

Predictable.

Controlled.

---

# Components

Every component serves one clear purpose.

Buttons.

Cards.

Exercise Cards.

Timers.

Progress Indicators.

Graphs.

Avoid multiple visual styles for identical functions.

Consistency builds trust.

---

# Information Density

Show only what matters now.

Everything else waits.

Information is progressively revealed.

The athlete should never need to search for the next action.

---

# Home Screen

The Home Screen answers one question immediately:

"What should I do today?"

The primary element is Today's Recommendation.

Everything else supports that decision.

Within three seconds the athlete should know exactly what today's objective is.

---

# Training Screen

Training mode removes everything unnecessary.

Only one exercise deserves attention.

Large exercise name.

Large prescribed load.

Large repetition target.

Large timer.

Minimal interaction.

The application disappears behind the training session.

---

# Statistics

Statistics exist to improve future decisions.

Not curiosity.

Every graph must answer a practical coaching question.

If a graph cannot influence future training,

it should not exist.

---

# Accessibility

CAS is designed for real-world training conditions.

Bright sunlight.

Dark gyms.

Sweaty hands.

Fatigue.

Stress.

High heart rate.

Every interaction must remain effortless.

Large touch targets.

High contrast.

Readable typography.

Minimal gestures.

Immediate feedback.

---

# Tone

CAS speaks like an experienced strength and conditioning coach.

Professional.

Calm.

Respectful.

Objective.

Never sarcastic.

Never childish.

Never theatrical.

The athlete is treated as a disciplined adult.

---

# Apple Principles

CAS follows principles similar to Apple's Human Interface Guidelines.

Clarity.

Deference.

Depth.

The interface supports content.

It never competes with it.

Elegance comes from simplicity.

Not decoration.

---

# Timelessness

Design trends evolve.

Human performance principles evolve slowly.

CAS prioritizes timeless design over fashionable aesthetics.

The interface should still feel appropriate ten years after its creation.

---

# Final Principle

The athlete should remember the training session.

Not the interface.

The interface has succeeded when it becomes invisible.

If users talk more about the design than about their progress,

the Design System has failed.
