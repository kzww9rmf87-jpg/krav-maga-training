# CAS Reference Architecture
## References

This document centralizes every scientific source used to justify the conceptual architecture of CAS.

References are progressively added as each chapter is completed.

---

## Priority of evidence

CAS prioritizes evidence according to the following hierarchy.

1. Consensus statements
2. Systematic reviews
3. Meta-analyses
4. Randomized controlled trials
5. Cohort studies
6. Expert consensus
7. Expert opinion

## Citation policy

Every important architectural decision should reference at least one scientific source whenever possible.

When no strong evidence exists, the document must explicitly state:

- Limited evidence
- Expert consensus
- Design choice

No unsupported statement should be presented as scientific fact.
